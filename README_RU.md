# 9router-antigravity-tray

Монитор квот пула аккаунтов Google Antigravity для 9Router в системном трее Windows. Суммирует проценты Gemini и Claude по всем подключенным ящикам и показывает ближайшее время сброса лимита.

[English](README.md) | [Русский](README_RU.md)

## Зачем это нужно

Скрипт выносит всю сводку по квотам Antigravity в системный трей Windows рядом с часами. Он читает локальную базу 9Router напрямую на компьютере, складывает проценты активных аккаунтов и показывает время до сброса лимитов без необходимости заходить в браузер.

## Возможности

- Суммирует общую квоту пула по всем активным аккаунтам.
- Рассчитывает время ближайшего сброса лимитов в минутах без лишнего текста.
- Контекстное меню в нативной темной теме Windows 11.
- Четкие шрифты без размытия на мониторах с масштабированием 125%, 150% и 200% (Per-Monitor V2 DPI).
- Быстрый параллельный опрос аккаунтов через пул потоков (занимает 1-2 секунды).
- Защита от дублирования процессов через именованный мьютекс Windows.
- Потребление памяти около 15 МБ RAM.

## Установка и запуск

### Требования
- Windows 10 или 11
- Python 3.9 или новее
- Установленный и запущенный локально 9Router

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/arturg-sudo/9router-antigravity-tray.git
   cd 9router-antigravity-tray
   ```

2. Запустите `install.bat`:
   - Установит зависимости (`pystray`, `pillow`).
   - Добавит ярлык в папку «Автозагрузка» для тихого запуска вместе с системой.
   - Запустит монитор в фоне.

Если хотите запустить вручную без автозагрузки:
```bash
pip install -r requirements.txt
wscript.exe run.vbs
```

## Управление

По правому клику на значок в трее:
- **Квоты и таймеры**: суммарный процент пула и остаток минут до сброса для Gemini и Claude.
- **Аккаунты**: список подключенных почт с их персональными процентами.
- **Стиль значка**: выбор между логотипом, числом процентов или комбинированным вариантом.
- **Обновить сейчас**: принудительный опрос API 9Router.
- **Выход**: закрытие программы.
