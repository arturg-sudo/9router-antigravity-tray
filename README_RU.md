# 9router-antigravity-tray

Монитор квот пула аккаунтов Google Antigravity для **OmniRoute** и **9Router** в системном трее Windows. Суммирует проценты Gemini и Claude по всем подключенным ящикам, поддерживает удалённые серверы и локальные роутеры, а также содержит графическое окно настроек.

[English](README.md) | [Русский](README_RU.md)

## Зачем это нужно

Скрипт выносит всю сводку по квотам Antigravity в системный трей Windows рядом с часами. Он может опрашивать как облачный сервер OmniRoute по API, так и локальные роутеры (9Router / OmniRoute) напрямую на компьютере, складывая проценты активных аккаунтов без необходимости заходить в веб-интерфейс.

## Возможности

- **Поддержка OmniRoute и 9Router**: подключение к облачным серверам (через API-ключ / Management Token) или к локальным инстансам.
- **Окно настроек GUI**: двойной клик по значку в трее открывает окно настроек в тёмной теме Windows 11 с живой проверкой соединения.
- **Быстрое переключение источников**: выбор между сервером и локальным роутером прямо из контекстного меню в 1 клик.
- **Суммарные квоты**: учёт 5-часовых сессионных и недельных лимитов для Gemini и Claude.
- **Нативный стиль Windows 11**: тёмное меню, монохромные значки (логотип '9', омни 'Ω', проценты % или комбо).
- **Поддержка High DPI (Per-Monitor V2)**: чёткий рендеринг без размытия на экранах 125%, 150% и 200%.
- **Параллельный опрос**: неблокирующее обновление за ~1 секунду через пул потоков, память ~15 МБ RAM.
- **Защита от дублей**: именованный Win32-мьютекс предотвращает повторный запуск.

## Установка и запуск

### Требования
- Windows 10 или 11
- Python 3.9 или новее
- Установленный и запущенный локально 9Router

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/arturg-sudo/9router-antigravity-tray.git
   cd 9router-antigravity-tray
   ```

2. Запустите `install.bat`:
   - Установит зависимости (`pystray`, `pillow`).
   - Добавит ярлык в папку «Автозагрузка» для тихого запуска вместе с системой.
   - Запустит монитор в фоне.

Если хотите запустить вручную без автозагрузки:
```bash
pip install -r requirements.txt
wscript.exe run.vbs
```

## Управление

По правому клику на значок в трее:
- **Квоты и таймеры**: суммарный процент пула и остаток минут до сброса для Gemini и Claude.
- **Аккаунты**: список подключенных почт с их персональными процентами.
- **Стиль значка**: выбор между логотипом, числом процентов или комбинированным вариантом.
- **Обновить сейчас**: принудительный опрос API 9Router.
- **Выход**: закрытие программы.
